# 🌐 Network Diagnostic Suite v1.3.0

O **Network Diagnostic Suite** é uma ferramenta profissional, portátil e completa para análise avançada de redes, monitoramento de conectividade, testes de desempenho e diagnósticos de infraestrutura.

Desenvolvido para profissionais de TI, SysAdmins e entusiastas, o aplicativo centraliza as principais ferramentas de rede em uma interface gráfica moderna e intuitiva, eliminando a necessidade de dezenas de comandos no terminal.

## 🚀 Principais Recursos

*   **📊 Dashboard em Tempo Real:** Monitoramento dinâmico do consumo de CPU, RAM, **Uso de Disco (Novo)** e identificação instantânea dos IPs local e público.
*   **🔄 Auto-Update Inteligente:** Esqueça os downloads manuais! O aplicativo verifica automaticamente a existência de novas versões e faz o download direto para o seu computador de forma nativa.
*   **🛤️ TCP Path Analyzer (Telnet Avançado):** Rastreie rotas de pacotes salto a salto em portas específicas, ideal para descobrir exatamente em qual roteador ou firewall uma conexão está sendo bloqueada.
*   **🚪 Port Scanner Inteligente:** Varredura de portas TCP rápidas para checagem de serviços. Inclui perfis de **preenchimento automático** com as portas de banco de dados, web e infraestrutura mais utilizadas do mercado.
*   **📡 Ping ICMP Avançado:** Teste de latência contínuo com gráficos em tempo real e cálculo preciso de perda de pacotes.
*   **🛣️ Traceroute & MTR:** Mapeamento completo de rotas até o destino, unindo o Tracert tradicional com a análise contínua do MTR.
*   **🌐 NSLookup:** Consulta e resolução de DNS rápida e eficiente para domínios.
*   **🚀 Speed Test Integrado:** Teste de velocidade de Download, Upload e Ping direto dos melhores servidores, ignorando limitações de terminal.
*   **📶 Diagnóstico de Wi-Fi:** Leitura profunda da interface de rede sem fio, exibindo IP, qualidade de sinal (ícone vetorial), canais e frequências.
*   **💾 Sistema de Exportação:** Salve os resultados de qualquer tela em `TXT`, `CSV` ou gere relatórios profissionais formatados em `PDF`.

## 🛠️ Como Usar (Instalação Portátil)

Este software é **100% Standalone (Portátil)** e otimizado para segurança nativa do Windows. Não é necessário instalar Python, dependências ou lidar com falsos positivos de antivírus.

1. Acesse a aba **[Releases](../../releases)** ao lado direito desta página.
2. Baixe a versão mais recente do arquivo `NetworkDiagnosticSuite.exe`.
3. Salve em qualquer pasta do seu computador ou Pen Drive.
4. Clique duas vezes no executável para abrir e usar! 
*(Para atualizações futuras, basta usar o botão "Verificar Atualizações" dentro da aba "Sobre" no próprio aplicativo).*
