# 🌐 Network Diagnostic Suite v1.0.0

O **Network Diagnostic Suite** é uma ferramenta profissional, portátil e completa para análise avançada de redes, monitoramento de conectividade, testes de desempenho e diagnósticos de hardware Wi-Fi.

Desenvolvido para profissionais de TI e entusiastas, o aplicativo centraliza as principais ferramentas de rede em uma interface gráfica moderna e intuitiva, sem a necessidade de usar o terminal de comandos.

## 🚀 Principais Recursos

*   **📊 Dashboard em Tempo Real:** Monitoramento do consumo de CPU, RAM e identificação instantânea dos IPs local e público, com gráficos dinâmicos.
*   **📡 Ping ICMP Avançado:** Teste de latência contínuo com gráficos em tempo real e cálculo de perda de pacotes.
*   **🛣️ Traceroute & MTR:** Mapeamento completo de rotas e saltos até o destino, unindo o Tracert tradicional com a análise contínua do MTR.
*   **🌐 NSLookup:** Consulta e resolução de DNS rápida e eficiente.
*   **🚀 Speed Test Integrado:** Teste de velocidade de Download, Upload e Ping direto dos melhores servidores, ignorando limitações de terminal.
*   **📶 Diagnóstico de Wi-Fi:** Leitura profunda da interface de rede sem fio, exibindo IP, qualidade de sinal via ícone vetorial, canais e frequências.
*   **🚪 Port Scanner:** Varredura de portas TCP rápidas (unitárias ou em massa) para checagem de regras de Firewall e serviços ativos.
*   **💾 Sistema de Exportação:** Salve os resultados de qualquer tela em `TXT`, `CSV` ou relatórios formatados em `PDF`.

## 🛠️ Como Usar (Instalação)

Este software é **100% Portátil (Standalone)**. Não é necessário instalar o Python ou configurar dependências na sua máquina.

1. Acesse a aba **[Releases](../../releases)** ao lado direito desta página.
2. Baixe a versão mais recente do arquivo `Network Diagnostic Suite.exe`.
3. Salve em qualquer pasta do seu computador ou Pen Drive.
4. Clique duas vezes no executável para abrir e usar!

## ⚠️ Aviso de Segurança e Antivírus (Falsos Positivos)

Como este é um software de diagnóstico de rede, ele executa operações profundas no sistema (como envio de pacotes ICMP, varredura de portas TCP e medições de tráfego de banda). 

Por ser um aplicativo desenvolvido de forma independente e distribuído sem uma assinatura digital corporativa paga (Certificado *Code Signing*), o **Windows Defender, SmartScreen ou navegadores de internet podem sinalizá-lo incorretamente como software suspeito (Falso Positivo)**.

**Como resolver caso seja bloqueado:**
*   **No Windows Defender/SmartScreen:** Clique em **"Mais informações"** e depois em **"Executar assim mesmo"**.
*   **No Antivírus:** Acesse o histórico de proteção e clique em **"Permitir no dispositivo"** ou **"Restaurar"** o arquivo executável.
*   O aplicativo é 100% seguro, de código aberto (open-source) e seu comportamento pode ser auditado a qualquer momento.
